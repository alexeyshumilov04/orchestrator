## 4. Дополнительно проверено (правило 6: «неизвестное ≠ ложь»)

* Порог непустоты куба **из данных** (`checks.properties.<role>.min_fraction = 0.05`) —
  реализован и **активен на живом прогоне**: в `agents/gates/G-VOL.json` находка
  `cube.metric_nonempty` = failed с сообщением «доля непустых ячеек 0.0181 % ниже порога 5.00 %
  (непустых 310)», статус `G-VOL` = `bypassed` (`degraded`). Проверка независимо воспроизведена
  пробой: с `nonempty_fraction` в свидетельстве → `failed`, без него → прежний критерий
  `count > 0` (порог применяется только там, где доля выводима — это заявленная семантика).
  Наблюдение: у пробника `domain/qc/probes.py:501` доля есть, поэтому на живом прогоне порог
  работает; для сторонних свидетельств без доли порог молча не применяется (см. H-03).
* `qaqc_coverage.json` (dry-каталог) — 6065 пунктов, `passed=0` на dry-run, причины у
  `unknown`/`not_applicable` присутствуют.
* Ключ `runs.dry_suffix` (разделение каталогов dry/execute) — читается из данных,
  мои инструменты и проверка `tests/test_model_artifacts.py` (35/0) это подтверждают.
