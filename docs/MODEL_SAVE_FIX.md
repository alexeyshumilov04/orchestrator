## 6.1 Почему модели не было: наш собственный код удалял её

`core/coordinator.py`, блок «ЧИСТЫЙ проект на каждый прогон» имел условие `if execute:`
и выполнялся **после** staged-прогона, который к этому моменту УЖЕ построил и сохранил
проект именно по этим путям (`agents/runner.py`: `base_snp = run_dir/<поле>.snp`).
То есть готовый проект базового прогона удалялся с диска сразу после сохранения.

```
БЫЛО:  base_snp = run_dir / f"{field}.snp"
       if execute:                     # ← безусловно, в т.ч. для staged-прогона
           ... rmtree(base_snp.snf); unlink(base_snp)     # УДАЛЯЛ готовую модель
СТАЛО: if execute and not staged:      # ← только там, где проект создаёт этот же код
```
Файл: `core/coordinator.py`, строки 1901–1922 (условие + комментарий F-30);
свидетельство сохранения — строки 1923–1931 (`проект базового прогона: … есть/НЕТ + размер .snf`).
Ветки ансамбля (`models/S00N`) этот блок не задевал — они создаются позже,
поэтому «модели веток есть, базовой нет» и складывалось впечатление «модели не сохраняются».

**102 байта — это НЕ пустышка, а нормальный дескриптор GD-проекта.** Содержимое проекта
лежит рядом в каталоге `<поле>.snf/`. Проба это подтвердила напрямую (см. 6.2).
