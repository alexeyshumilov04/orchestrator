## 5. Как это влияет на решения агентов

`agents/knowledge.StaticKnowledge` (уже существует) читает все три файла по путям из
`config.yaml → agents.literature.*`:

```
literature_sources   = 816      # ontology/literature_index.csv
literature_rules     = 83       # базовый набор BDI v4.1
literature_rules_ext = 55       # ontology/literature_rules_ext.csv   ← новое
literature_all       = 138
agent_literature     = 8        # ontology/agent_literature_map.yaml
```

**Найденный разрыв (требует 1 строки в файле Lead'а).** `StaticKnowledge.rules_for(
branch_id=..., activity=...)` собирает правила из `decisions()` и `literature_rules()`,
но **не** из `literature_rules_ext()`:

```python
# agents/knowledge.py, строка 373 — сейчас:
for source in (self.decisions(), self.literature_rules()):
# нужно:
for source in (self.decisions(), self.literature_rules(), self.literature_rules_ext()):
```

Проверено фактом: `rules_for(branch_id='BR_VARIOGRAM')` возвращает 4 правила и **0
литературных**, хотя в этой развилке 3 новых правила (`RULE_LIT_GSTAT_010/020/030`).
Пока правка не сделана, литература доступна через `literature_rules_ext()` /
`literature_rules_all()`, но не подмешивается к решениям агента автоматически.
Файл `agents/**` — вне моей зоны записи (задание E13), поэтому это ЗАПРОС к Lead.

## 6. Пробелы (честно)

1. **159 файлов без извлекаемого текста** — сканы-образы (преимущественно короткие курсы
   в «Мануалы (вспомогательное)», часть петрофизики и ГИС). Проиндексированы по метаданным,
   но цитат из них нет. Закрывается OCR (вне объёма E13).
2. **Папка «Онтологическая модель — копия» пуста** (0 файлов) — источников по
   онтологическому моделированию в ней нет.
3. **Старые бинарные форматы**: 24 `.doc`, 1 `.ppt`, 1 `.xls`, 1 `.djvu` — имеющимся стеком
   (pymupdf/pdfminer/python-pptx/openpyxl; `python-docx` не установлен) текст не извлекается,
   в индексе только имя/метаданные.
4. **Нет литературных источников по**: гидродинамической адаптации и ГТМ (блок 12 чеклиста) —
   в «Литературе» это представлено лишь общими курсами; PVT-константы Арчи `m, n, a` для
   Герасимовского (литература даёт модели, проект даёт значения — проверка `QC_PHYS_005`
   остаётся `not_applicable` без SCAL); лабораторные SCAL-кривые.
5. **48 правил — `EVIDENCE_BACKED_CANDIDATE`**: числовые пороги (например «ансамбль ≥100
   реализаций», «3–5 ячеек между скважинами») взяты из источников разного уровня и должны
   быть согласованы с методикой ГПН до production-применения.
6. **8 из 55 правил не привязаны к агенту** (неопределённости/ансамбль) и **`AG_GEOSTATISTICS`
   отсутствует в коде**: это структурное ограничение прототипа, а не пробел литературы —
   оно зафиксировано в карте (`status: absent_in_code` / `no_agent_in_code`), а не замаскировано.
