Ты — автономный агент, управляющий пайплайном оркестратора. Твоя задача — выполнить 4 команды по очереди и сохранить результаты каждой в отдельный файл.

Подготовка:
Сначала создай в текущей директории папку `harness_logs` (если её нет).

Команды для выполнения (строго по одной):
1. `python -X utf8 main.py preflight`
2. `python -X utf8 main.py plan --field Герасимовское`
3. `python -X utf8 main.py run --field Герасимовское`
4. `python -X utf8 main.py run --field Герасимовское --execute --ensemble-size 1`

Действия после каждой команды:
1. Запусти команду.
2. Сохрани ВЕСЬ вывод терминала (без сокращений, пересказов и фильтрации) в текстовый файл внутри папки `harness_logs`:
   - Для шага 1: `harness_logs/01_preflight.txt`
   - Для шага 2: `harness_logs/02_plan.txt`
   - Для шага 3: `harness_logs/03_dry_run.txt`
   - Для шага 4: `harness_logs/04_execute.txt`
3. В самом файле в первой строке напиши саму команду, а начиная со второй строки — сырой лог.

Обработка ошибок:
Если на шаге 4 возникнет ошибка (например, отсутствие папки `Maps`), сохрани лог с ошибкой в файл, затем создай нужную папку (`Maps`) и перезапусти команду, сохранив новый лог в тот же файл `04_execute.txt` (дописав его в конец).

Финальный ответ в чате:
После выполнения всех шагов просто напиши: "Все 4 команды выполнены. Логи сохранены в папку harness_logs. Файлы: 01_preflight.txt, 02_plan.txt, 03_dry_run.txt, 04_execute.txt. Краткий итог: ... (1-2 предложения)".
