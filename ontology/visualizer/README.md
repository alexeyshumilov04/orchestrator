# Визуализатор GeoModelingEvolutionOntology v4.1

Откройте `dist/index.html` в современном настольном браузере. Данные встроены в `ontology-data.js`; интернет и локальный сервер не требуются.

Основной маршрут: **Процесс → Подпроцесс → подэтап → атомарная операция → правая панель отношений**. Из карточки доступны входы, выходы, методы, условия перехода, параметры, QA/QC, точки BDI-решений и программные операции. Режим **Решения BDI** показывает все 300 развилок и 1 796 правил в порядке приоритета, guard-условия, результат, намерение и необходимость подтверждения эксперта. Профили агентов, модули `TypicalAgentRuntime`, capabilities, handoff-контракты и политики автономии доступны в каталоге, поиске и графе связей.

Глобальный поиск индексирует русские/английские подписи, IRI, функции, параметры, QA/QC и guard expressions. Кнопка «Открыть RDF» позволяет временно просмотреть другой монолит или набор взаимосвязанных `.rdf`/`.nt` файлов без изменения исходной онтологии.

Сборка данных после изменения онтологии:

```powershell
python build_visualizer.py
```

Проверка:

```powershell
python validate_visualizer.py
```

Статические исходники интерфейса находятся в `src`, готовая локальная сборка — в `dist`. Публикация не выполнялась.
